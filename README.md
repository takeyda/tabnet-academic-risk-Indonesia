# tabnet-academic-risk-Indonesia

About
TabNet-based early warning system for identifying at-risk students in Indonesian junior high schools, integrated with four XAI methods (Attention Masks, SHAP, LIME, Counterfactual) and an offline Streamlit dashboard in Bahasa Indonesia.

Requirements
python >= 3.8
pytorch-tabnet
xgboost
lightgbm
shap
lime
scikit-learn
imbalanced-learn
optuna
streamlit
pandas
numpy
torch
scipy
matplotlib
seaborn

Data
Raw student data cannot be shared publicly due to privacy constraints. Contact the corresponding author at tasya.yustira@nusaputra.ac.id for replication requests.
